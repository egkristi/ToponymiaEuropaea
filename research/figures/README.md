# Research Figures

Publication-quality figures generated by the analysis pipeline.

Generated files are in `.pdf` (vector) and `.png` (raster) formats.

## Style
- Font: Serif (Times-like), 10pt body
- Colour palette: Colourblind-safe (Wong 2011)
- Width: 3.5" (single column) or 7.0" (double column)
- Resolution: 300 DPI

## Regenerating
```bash
uv run python research/notebooks/01_heim_distribution.py
```
